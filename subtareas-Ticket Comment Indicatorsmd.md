# Subtareas — [TICKETING] Ticket Comment Indicators

## Subtarea 1

**Title:** Include comment count in ticket list data

**Description:**
As a developer, I need the ticket list endpoint to provide the number of comments associated with each ticket, so that the frontend can determine whether a comment indicator should be displayed. The endpoint already exists, but it currently does not return the comment count information required by this feature.

---

## Subtarea 2

**Title:** Display comment indicator on tickets with comments

**Description:**
As a user, I want to see a comment icon on tickets that contain comments, so that I can quickly identify tickets with active feedback from the ticket list.

---

## Subtarea 3

**Title:** Apply styling and responsive behavior to comment indicator

**Description:**
As a user, I want the comment indicator to be displayed correctly across different screen sizes, so that the ticket list remains clear and usable on desktop and mobile devices.

---

## Subtarea 4

**Title:** Add tests for comment indicator visibility

**Description:**
As a developer, I want automated tests covering the comment indicator behavior, so that future changes do not break the feature.
